Miampic

截图、上传或右键图片，一键生成适合 AI 生图的提示词。支持中英切换、比例约束、历史记录和日夜间模式。

下载插件 V1.0.1 查看 GitHub

核心能力

把图片理解、提示词生成和复制使用串成一个更短的流程。

图片分析

截图 / 上传 / 右键

从网页区域、本地图片或页面图片快速获取参考图，减少来回复制和切换。

提示词生成

直接生图 / 辅助改图

根据不同用途生成对应提示词，既能直接生图，也能配合原图做风格迁移。

比例约束

默认 9:16，可自由切换

支持 9:16、3:4、1:1、16:9 等常用比例，并写入生成要求中。

安装步骤

当前为开发者模式安装，下载后需要先解压。

1
下载插件压缩包点击上方按钮下载 miampic-extension.zip。
2
解压文件将 zip 解压到一个固定文件夹，后续不要随意删除这个文件夹。
3
打开扩展管理页在 Chrome 或 Edge 地址栏输入 chrome://extensions/。
4
开启开发者模式打开页面右上角的开发者模式开关。
5
加载已解压的扩展选择解压后的 miampic-extension 文件夹即可。

更新说明

从 1.0.0 到 1.0.1，主要是把真实使用中的细节补齐。

1.0.1

  • 新增 图片比例设置，支持 9:16、3:4、1:1、16:9 等常用比例，并写入提示词生成要求。
  • 新增 日间 / 夜间模式切换，popup、设置页和提示词弹窗统一适配。
  • 新增 提示词弹窗与历史记录中的图片比例 tag。
  • 优化 提示词弹窗的尺寸调整、自定义缩放角标、尺寸记忆和文本区域布局。
  • 优化 受限页面提示、popup 暗色渐变、设置页按钮和历史记录视觉细节。
  • 修复 Gemini 翻译路径、流式解析 buffer、翻译后顶部空行、生成完成后弹窗高度回退等问题。

1.0.0

  • 新增 截图分析、上传图片、右键图片生成提示词三种入口。
  • 新增 直接生图与辅助改图两种提示词用途。
  • 新增 硅基流动与 Google Gemini 两个 API 平台配置。
  • 新增 中英文提示词生成与翻译切换能力。
  • 新增 设置页、历史记录、复制提示词和一键跳转生图工具。
